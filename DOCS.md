# ProofTheory Documentation

This repository contains Coq proofs and definitions related to arithmetic and basic number theory.

## Files

1. **QandPA.v**: Contains basic arithmetic definitions and operations.
2. **proofs_with_omega.v**: Contains proofs using the Omega library for automated reasoning.

## Dependencies

- Coq
- Omega library

## Usage

To compile and verify the proofs, you can use the following command:

```
coqc QandPA.v proofs_with_omega.v
```
